Trang Facebook

Cần Page Access Token (không phải access token cá nhân) với quyền pages_manage_posts và pages_read_engagement. Cách lấy nhanh:

  1. Vào developers.facebook.com → tạo App loại "Business".
  2. Thêm sản phẩm "Facebook Login" và "Pages API".
  3. Dùng Graph API Explorer (developers.facebook.com/tools/explorer): chọn App của bạn → chọn quyền pages_show_list, pages_manage_posts, pages_read_engagement → Generate Access Token → đăng nhập Facebook.
  4. Gọi GET /me/accounts trong Explorer để lấy danh sách Page + Page Access Token tương ứng (token này không hết hạn nếu App ở chế độ Live và bạn là admin trang).
  5. Dán Page ID và Page Access Token vào form bên dưới.
